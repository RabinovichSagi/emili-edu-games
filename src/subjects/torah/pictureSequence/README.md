# רצף תמונות בפרשה

משחק **רצף תמונות בפרשה** הוא מיני־משחק בתורה שבו הילד/ה בוחר/ת פרשת שבוע ומסדר/ת סדרת תמונות לפי רצף הסיפור.

## מטרת למידה

- להבין רצף אירועים בסיפור מהפרשה.
- לתרגל שפה סיפורית: מה קרה קודם, מה אחר כך, ומה הסימן בתמונה.
- לחזק זיכרון חזותי והבנת הנקרא/הנשמע בלי לחץ ובלי ענישה.

## מבנה תוכן

התוכן מאורגן בשלוש רמות:

1. **חומש** — בראשית, שמות, ויקרא, במדבר, דברים.
2. **פרשה** — למשל `בראשית` בתוך חומש בראשית.
3. **סיפורי רצף** — כל פרשה יכולה להכיל הרבה סיפורים, והמשחק מערבב ביניהם בכל סיבוב.

ברירת המחדל היא תמיד הפרשה האחרונה שנוספה לפי `addedAt`, כדי שיהיה קל להוסיף בכל שבוע את פרשת השבוע החדשה.

## פרשת הדוגמה הראשונה

המשחק כולל דוגמה ראשונה עבור **פרשת בראשית**: ארבעת ימי הבריאה הראשונים.

- יום ראשון: אור וחושך.
- יום שני: רקיע ושמים.
- יום שלישי: יבשה וצמחים.
- יום רביעי: מאורות.

הנכסים נמצאים תחת:

```text
public/torah/pictureSequence/bereshit/creation-days-four/
```

## רמות קושי

- **קל**: 4 תמונות.
- **בינוני**: עד 5 תמונות כאשר יש מספיק תמונות בסיפור.
- **מתקדם**: עד 6+ תמונות כאשר יש מספיק תמונות בסיפור.

הסיפור עצמו מגדיר את כל התמונות האפשריות. המשחק בוחר כמה מהן להציג לפי רמת הקושי.

## מניעת ניחוש עיוור

המשחק לא מעניש טעויות. במקום זאת הוא מזהה דפוסים שמרמזים על ניחוש:

- סידור מהיר מאוד של כל התמונות.
- הרבה פעולות ברצף בקצב מהיר.
- טעויות חוזרות באותו סיבוב.

כאשר מזוהה ניחוש, המשחק עובר ל־**מצב זהיר**:

- מאט את האינטראקציה לזמן קצר.
- מבקש להתבונן בתמונות לפני שממשיכים.
- מדגיש מקומות שצריכים בדיקה.
- מעודד שימוש ברמזים במקום ניסוי אקראי.

## משוב ורמזים

- תשובה נכונה נותנת משוב חם ומיידי.
- תשובה שגויה מסמנת רק את המקומות שצריכים מחשבה נוספת.
- כפתור **רמז** מציג רמז ממוקד למיקום הראשון שדורש תיקון.
- תמיד אפשר לנקות ולנסות שוב.

## מדדים ודוחות

המשחק מדווח למנגנון הכללי של האפליקציה:

- דיוק.
- זמן תגובה ממוצע.
- רצף הצלחות.
- תרגול אחרון.
- מאסטרי לפי פריטי spaced repetition.

מפתח הפריט הוא ברמת סיפור הרצף, למשל:

```text
bereshit|creation_days_1_4|days_1_4
```

כך כל סיפור בפרשה יכול לקבל תזמון חזרה משלו.

## איך להוסיף פרשה או סיפור חדש

ערכו את `content.js`:

1. הוסיפו או עדכנו פרשה ב־`TORAH_PARASHOT`.
2. הגדירו `bookId`, `titleHe`, `subtitleHe`, ו־`addedAt`.
3. הוסיפו מערך `stories`.
4. לכל סיפור הגדירו `id`, `titleHe`, `promptHe`, `itemKey`, ו־`cards`.
5. לכל כרטיס הגדירו `id`, `order`, `titleHe`, `hintHe`, `image`, ו־`altHe`.
6. שימו נכסים סטטיים תחת `public/torah/pictureSequence/<parasha>/<story>/`.

כל מחרוזות ה־UI חייבות להיות בעברית, והנתיבים חייבים להיות יחסיים כדי שהמשחק יעבוד ב־GitHub Pages.
